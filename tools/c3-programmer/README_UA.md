# C3-програматор для WT32-ETH01

*[English](README.md)*

Прошивка для **ESP32-C3 SuperMini**, яка перетворює його на програматор і послідовний монітор WT32-ETH01:

- **Через Wi-Fi (RFC2217):** `esptool` / `idf.py` прошивають і читають лог WT32 як звичайний порт `rfc2217://c3prog.local:4000`. Швидкість і DTR/RTS передаються по мережі: RTS → EN, DTR → IO0, як на звичайному USB-UART з автоскиданням.
- **Через USB (запасний шлях):** USB C3 ↔ UART WT32 на фіксованих 115200. Бутлоадер — кнопкою або з веб-сторінки.
- **Веб-сторінка** `http://c3prog.local`: вибір Wi-Fi, стан, кнопки «Перезапустити» і «Режим прошивки» для WT32, оновлення прошивки самого C3.

> Статус: зібрано (ESP-IDF 6.1), на залізі **не перевірено**.

## 1. Прошити C3 готовим бінарником

Файл: [`firmware/c3-programmer.bin`](firmware/c3-programmer.bin) — один образ, пишеться з адреси `0x0`.

**З браузера (Chrome/Edge, нічого не встановлювати):** https://espressif.github.io/esptool-js/ → *Connect* → вибрати порт C3 → *Flash Address* `0x0`, файл `c3-programmer.bin` → *Program*.

**Або esptool:**
```bash
pip install esptool
esptool.py --chip esp32c3 -p /dev/ttyACM0 write_flash 0x0 c3-programmer.bin    # Windows: -p COM5
```

Якщо C3 не видно як порт: утримуйте BOOT, натисніть RESET, відпустіть BOOT — і повторіть.

## 2. Підключити до Wi-Fi

1. Після прошивки C3 піднімає точку доступу **`C3prog-Setup-XXXX`** (відкрита). Світлодіод блимає подвійно.
2. Підключіться до неї телефоном — сторінка налаштування відкриється сама (якщо ні — http://192.168.4.1). Пароль сторінки — `12345678`; змініть його в розділі «Пароль сторінки».
3. Оберіть мережу, введіть пароль, за бажанням змініть імʼя пристрою → «Зберегти і перезапустити».
4. C3 підключиться до мережі; сторінка — `http://c3prog.local` (або IP з роутера). Світлодіод горить рівно.

Якщо збережена мережа недоступна 60 с, точка налаштування вмикається знову (C3 при цьому далі пробує підключитися).

## Оновлення прошивки C3 через сторінку (OTA)

Розділ «Оновлення прошивки» на сторінці: файл **`firmware/c3-programmer-ota.bin`** → «Оновити прошивку». Повний образ `c3-programmer.bin` (для адреси `0x0`) сторінка відхилить — він лише для прошивки кабелем.

- Перед записом перевіряється, що образ для цього чипа і цієї прошивки; після запису — цілісність.
- Флеш має два слоти (`ota_0`/`ota_1`, по 1,875 МБ); нова прошивка пишеться в неактивний, старий лишається.
- Після перезапуску нова прошивка **на перевірці 60 с**: якщо за цей час вона впаде або перезапуститься, завантажувач повертає попередню. Сторінка покаже, яка версія реально працює.
- Сесії не переживають перезапуск — сторінка попросить увійти знову.
- Перший раз прошивку з цією розміткою треба записати кабелем (повний образ з `0x0`); налаштування (NVS) при цьому зберігаються.

## Підключення до WT32

Схема і кроки першої прошивки: [`docs/WIRING_UA.md`](../../docs/WIRING_UA.md).

| C3 SuperMini | WT32-ETH01 | Примітка |
|---|---|---|
| GPIO4 (UART1 TX) | RXD (IO3) | |
| GPIO5 (UART1 RX) | TXD (IO1) | внутрішня підтяжка вгору на C3 |
| GPIO6 | EN | open-drain: лише тягне вниз або відпускає |
| GPIO7 | IO0 | open-drain; після старту WT32 завжди відпущений (IO0 = тактування Ethernet) |
| 5V | 5V | лише на столі; **не 3V3** |
| GND | GND | обовʼязково |

## Кнопка BOOT і світлодіод на C3

| Утримання | Дія |
|---|---|
| < 1 с | WT32 → режим прошивки |
| 1–5 с | перезапуск WT32 |
| 5–10 с | перезапуск самого C3 |
| ≥ 10 с | забути Wi-Fi і скинути пароль сторінки на `12345678` (C3 повертається в режим налаштування) |

Світлодіод: подвійне блимання — точка налаштування; 1 Гц — підключення до Wi-Fi; горить — готовий; мерехтить — обмін з WT32.

## Прошивка WT32 через Wi-Fi

```bash
esptool.py --chip esp32 -p rfc2217://c3prog.local:4000 flash_id
idf.py -p rfc2217://c3prog.local:4000 flash monitor
```

Лише монітор (без `idf.py`):
```bash
python -m serial.tools.miniterm --rts 0 --dtr 0 rfc2217://c3prog.local:4000 115200
```
`--rts 0 --dtr 0` обовʼязково: за замовчуванням pyserial піднімає RTS, і WT32 висить у скиданні.

Якщо `.local` не резолвиться (часто на Windows без Bonjour), використовуйте IP зі сторінки стану.

Якщо автоскидання по мережі не спрацьовує: на сторінці натисніть «Режим прошивки» (або коротко BOOT на C3), потім `esptool.py ... --before no_reset ...`.

## Прошивка WT32 через USB (запасний шлях)

USB C3 не передає швидкість і DTR/RTS, тому:
- лише `-b 115200`;
- `--before no_reset --after no_reset`: сигнали скидання з ПК скидали б сам C3, а не WT32.

```bash
# 1. «Режим прошивки» на сторінці або коротко BOOT на C3
cd build   # тека збірки прошивки WT32
esptool.py --chip esp32 -p /dev/ttyACM0 -b 115200 --before no_reset --after no_reset write_flash @flash_args
# 2. «Перезапустити» на сторінці або BOOT 1–5 с
```

Монітор: `python -m serial.tools.miniterm --dtr 0 --rts 0 /dev/ttyACM0 115200`
(`--dtr 0 --rts 0`, щоб не скинути C3).

## Збірка з вихідників

```bash
. $IDF_PATH/export.sh            # ESP-IDF ≥ 5.1, перевірено на 6.1
cd tools/c3-programmer
./build_firmware.sh              # → firmware/c3-programmer.bin (кабель, 0x0) і c3-programmer-ota.bin (сторінка)
# або: idf.py set-target esp32c3 && idf.py build flash
```

Wi-Fi і портал налаштування — спільний компонент [`shared/wifi_setup`](../../shared/wifi_setup). Залежності (`rfc2217-server`, `mdns`) тягнуться з GitHub. Піни, порт RFC2217, потужність Wi-Fi — `idf.py menuconfig` → *C3 Programmer Configuration*.

## Відомі обмеження

- Один мережевий клієнт RFC2217 одночасно.
- Якщо ноутбук зник посеред сесії (сон, обрив Wi-Fi), бібліотека RFC2217 може не помітити розриву і не прийматиме нових зʼєднань. Лікується перезапуском C3 (BOOT 5–10 с).
- Сторінка під паролем (за замовчуванням `12345678`), але сам порт RFC2217 (4000) — без пароля: будь-хто в тій самій мережі може прошити або скинути WT32. Для домашнього стола прийнятно.
- Точка налаштування відкрита (без пароля Wi-Fi); сторінка за нею — під паролем.
- Потужність Wi-Fi за замовчуванням знижена до 8,5 дБм — типове лікування проблем антени SuperMini. Якщо зв'язок слабкий, змініть у `menuconfig`.
- Лог самого C3 виводиться лише на UART0 (GPIO21), бо USB віддано під дані WT32.
