# Тести входу і мов

*[English](README.md)*

Сторінку WT32 (з режимами) перевіряють її власні тести у `wt32/test/`; `i18n_flow.js` звідси запускається на обох сторінках.

`auth.js` + сторінка застосунку проти імітації API (`mock_portal.py` повторює поведінку `setup_portal.c` / `portal_auth.c`; `mock_i18n.py` віддає `/i18n.json` і помилки з ключами з тих самих файлів `i18n/<code>.json`, з якими збирається прошивка):

- `login_flow.js`: одна форма входу на паралельні 401, невірний пароль, вхід з `12345678`, попередження про стандартний пароль, зміна пароля, вихід і вхід з новим;
- `i18n_flow.js`: перемикач мови на формі входу, помилка пристрою обраною мовою, жодного англійського тексту на сторінці українською і жодної кирилиці англійською, вибір зберігається після перезавантаження, мова браузера за замовчуванням, дані прошивки (версія, час збірки, коміт, SHA-256).

```bash
cd shared/wifi_setup/test
python3 mock_portal.py ../../../tools/c3-programmer/main/portal.html ../auth.js 8802 ../../../tools/c3-programmer/main/i18n &
node login_flow.js 8802 c3     # потрібен playwright; імітація запамʼятовує стан: перед наступним тестом перезапустіть її
kill %1
python3 mock_portal.py ../../../tools/c3-programmer/main/portal.html ../auth.js 8802 ../../../tools/c3-programmer/main/i18n &
node i18n_flow.js 8802 c3
kill %1
```
`CHROMIUM=/шлях/до/chrome` — якщо Playwright має використати вже встановлений браузер.

Самі мовні файли: `python3 ../tools/i18n_bundle.py check --complete <теки i18n> --sources <сторінки й вихідники>` (повна команда для кожного застосунку — в його README).
